# Fake_News_Detection_Using_Machine_Learning

# Summary

This project implements a Machine Learning–based Fake News Detection system that classifies news articles as Fake or Real using Natural Language Processing (NLP) techniques. The system preprocesses textual data, extracts meaningful features, and applies multiple supervised learning models to improve prediction reliability.


# Overview

With the rapid growth of digital media, fake news spreads quickly and impacts public opinion. Manual verification is inefficient and time-consuming. This project provides an automated solution using NLP and Machine Learning to detect fake news articles based on textual patterns learned from historical data.



# Problem Statement

The increasing volume of fake news on online platforms makes it difficult to identify credible information. There is a need for an automated, scalable, and accurate system to classify news articles as fake or real.



# Key Objectives

Clean and preprocess raw news text data

Convert text into numerical features using NLP techniques

Train and evaluate multiple ML classification models

Compare model performance to improve accuracy

Enable manual testing for real-time news classification
